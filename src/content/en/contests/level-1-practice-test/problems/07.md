Which of these numbers is divisible by 9?

## Solution

A number is divisible by 9 when its digits add up to a multiple of 9. Add up the digits of each choice:

- 1,234: $1 + 2 + 3 + 4 = 10$
- 2,024: $2 + 0 + 2 + 4 = 8$
- 5,511: $5 + 5 + 1 + 1 = 12$
- 7,302: $7 + 3 + 0 + 2 = 12$
- 4,518: $4 + 5 + 1 + 8 = 18$

Only 18 is a multiple of 9. You can check: $9 \times 502 = 4518$.

**Answer: (E) 4,518**
