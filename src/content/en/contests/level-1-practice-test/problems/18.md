Figure 1 is one square made from 4 toothpicks. To make each new figure, you attach one more square to the right end of the row. The new square shares a side with the last one. How many toothpicks are in Figure 20?

## Solution

Try small cases. Figure 1 uses 4 toothpicks. Each new square shares one side, so it needs only 3 new toothpicks. Figure 2 uses $4 + 3 = 7$, and Figure 3 uses $7 + 3 = 10$.

Figure 20 has 19 new squares after the first one: $4 + 19 \times 3 = 61$.

If you picked 80, you gave every square 4 toothpicks, but each shared side counts only once.

**Answer: (C) 61**
