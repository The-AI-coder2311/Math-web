Five fair dice are rolled. What is the expected number of dice that show a number greater than 4?

## Solution

One die shows a 5 or a 6 with probability $\frac{2}{6} = \frac{1}{3}$, so the expected count from one die is $\frac{1}{3}$. Expected values add, so for 5 dice the expected number is $5 \times \frac{1}{3} = \frac{5}{3}$.

**Answer: (C) $\frac{5}{3}$**
